# Arrows Reveal — catálogo de imágenes

Archivos que la app Arrows Reveal descarga para agregar imágenes nuevas sin publicar una actualización.
Se generan con `scripts/build-catalog.mjs` desde el proyecto del juego; no se editan a mano.

- `catalog.json`: lista de packs e imágenes (solo se agregan cosas al final).
- `<pack>/<imagen>.jpg`: las imágenes.
